# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0]

### Added

- Local climate control, separate operating mode and fan controls, and filter reset.
- Air temperature, humidity, fan speed, boost, alarm, and filter monitoring.
- Connection reconfiguration, configurable polling, and redacted diagnostics.
- Marketplace and HACS installation, local brand assets, and a release archive.
