# Security policy

Use [GitHub private vulnerability reporting](https://github.com/voluzi/ha-vents-ahu/security/advisories/new)
to report a vulnerability in Vents AHU. Please include the affected version,
the impact, and steps to reproduce it with synthetic data. Keep the report private
while a fix is being prepared.

Use the [issue tracker](https://github.com/voluzi/ha-vents-ahu/issues) for ordinary bugs and feature requests.
